Getting started / 03

Use NAVA your way.

A practical command guide for installation, wake phrases, smart-grid control, dictation, apps, browsers, and Office.

Offline speech toolsWindows 10 / 11Voice-first control

Install

  1. Download the 64-bit Windows installer from the project release page.
  2. Run setup and choose desktop or sign-in startup shortcuts if needed.
  3. The private runtime and offline speech assets are included; Python does not need to be installed separately.
NAVA AI is a rule-based computer assistant with offline speech tools, not a general-purpose chat model.

Smart grid

Say open grid or grid on to show adaptive labels for visible controls.

  • Click B or double click C activates a labelled target.
  • Move to G moves the pointer without clicking.
  • Scroll up and scroll down scroll the active target or app.
  • Grid off hides the labels.

Dictation and text editing

  • Dictation on / dictation stop starts or ends offline dictation.
  • Backspace / erase removes the last typed word or character according to the active mode.
  • Select from Islamabad to Karachi selects text between spoken endpoints.
  • Copy, paste, and punctuate it edit the active selection or focused field.

Apps, files, browsers

Open or switch to apps, files, and folders using familiar names. Browser commands support tabs and media actions such as pause, resume, forward, rewind, next video, and skip ad where the target exposes those controls.

Word, Excel, and PowerPoint

Use worksheet ranges, named dropdowns, formatting, and table actions where the desktop Office app exposes the relevant controls.

If a command depends on a visible control, keep that app in view. When several targets match, NAVA shows a labelled choice instead of guessing.
