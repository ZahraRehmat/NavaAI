ABOUT NAVA AI

More ways to use
your own computer.

Everyday computer tasks can be difficult when using a keyboard or mouse is painful, tiring, or not possible. We are building NAVA AI to make more of those tasks reachable through voice.

Our goal is practical: help people open apps, find controls, navigate websites, and write text with clear spoken commands. We are starting with a Windows assistant and will keep improving it with people who need more accessible ways to use a computer.

GOOD TO KNOW

Questions,
answered.

What does the installer include?+

The standalone installer includes NAVA AI, its private Python runtime, required libraries, offline speech and punctuation models, OCR assets, and browser support. You don’t need Python or pip installed.

Does NAVA need the internet?+

Voice recognition and punctuation run locally after installation. Downloading the installer requires internet, and websites need an internet connection.

Does it understand every request?+

No. NAVA performs supported commands through direct controls. Speech can be misheard, and some apps or controls may not expose accessible targets. If targets are ambiguous, it can ask you to choose.

Does it need Microsoft Office?+

Only if you want to use Office features. Those commands require the relevant desktop Office app installed on your PC.

What Windows versions are supported?+

The preview installer targets 64-bit Windows 10 (version 2004 or later) and Windows 11. Windows 10 acceptance testing is still pending; Windows 11 is the version validated by the project.

Is this a general-purpose AI chatbot?+

No. It uses offline models for speech recognition and punctuation, while supported computer tasks are handled by rules and native Windows controls.
