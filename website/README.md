# NAVA AI website

Static product website for the NAVA AI Windows assistant. It includes product information, capabilities, limitations, About, FAQ, Contact/GitHub, and official Windows release download links.

## Preview locally

Open `index.html` in a browser, or serve this folder with any static file server. No build step is required.

The download buttons currently link to the official GitHub Release installer (`v1.0.0-preview.1`). Hosting and custom domain configuration are intentionally left for the deployment phase.
