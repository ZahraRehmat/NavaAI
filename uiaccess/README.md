# Windows shell overlay support

Word dropdown scanning works without this installer. Windows Start uses a higher display band than ordinary Tk windows. Microsoft documents UIAccess as the supported accessibility mechanism for staying visible over the Windows UI: https://learn.microsoft.com/en-us/windows/win32/winauto/uiauto-securityoverview

This helper only paints the same vector annotations generated by Gwen. It has no keyboard/mouse injection, process termination, app automation, shell execution or document-reading commands. A per-session named pipe restricted to the current Windows user carries drawing frames. Closing Gwen's pipe exits the helper. It will not run as an overlay unless its token actually has UIAccess.

`build.ps1` compiles a .NET Framework WinForms executable with an `asInvoker`, `uiAccess=true` manifest. The build does **not** install anything or create trust. `install.ps1` requires administrator approval. It creates a non-exportable local code-signing certificate, adds its public certificate to this computer's Root and TrustedPublisher stores, signs the executable and places it in `%ProgramFiles%\Gwen Accessibility`. UAC policies, secure-desktop settings, other Python executables and the main Gwen process are not modified. For distribution, replace this local-development signing step with an organization-controlled trusted code-signing certificate.

After installation, Gwen discovers the helper automatically. Its pipe handshake must report a real UIAccess token before Gwen hides its ordinary Tk grid. Without the helper, the existing overlay continues to work on ordinary applications and popup menus; it cannot claim visibility above every Windows shell surface.

`uninstall.ps1`, run as administrator after Gwen is closed, removes only the recorded helper files and its certificate thumbprint from the three stores. It does not recursively delete directories or change security policy. No private signing key is exported to the project or repository.

The helper's `--render-test OUTPUT.png` mode draws JSON vector commands from standard input into a bitmap without creating an overlay window. Use an ordinary unsigned diagnostic build (no UIAccess manifest) for this test before installation.
